# Mesh Relay user guide

Mesh Relay is an Android app that listens to a Meshtastic node over Bluetooth and shows **which
nodes forward packets to you**, and **how strong and how clean the signal from each of them is**.

This guide covers version **0.6.1**. Every screenshot was taken from the app's built-in demo
device with made-up data, so the numbers are illustrative and no real node appears in them. The demo's
made-up nodes are placed in real towns, so you will see town names and coordinates.
